## ゲーム概要

### コンセプト
このゲームは、2人のプレイヤーが対戦するターン制のデジタルカードゲームです。プレイヤーはユニットを召喚し、スペルを使用して相手プレイヤーを倒すことを目指します。

### ゲームの目的
相手プレイヤーのHPを0にするか、相手のデッキを尽きさせることで勝利します。

### 特徴
- **シンプルな基本ルール**: 初心者でも理解しやすい
- **戦略的な深さ**: カードの組み合わせと使用タイミングが重要
- **リソース管理**: マナシステムによるターンごとの戦略
- **多様な特性**: Rush、Guardianなどの特殊能力

## 基本ルール

### ゲームの準備

#### プレイヤーの初期状態
| 項目 | 値 |
|------|-----|
| HP | 20 |
| 最大HP | 20 |
| 初期マナ | 1 |
| 最大回復マナ | 1 |
| 初期手札 | 4枚 |
| デッキ枚数 | 25枚（標準） |

#### ゲーム開始時
1. 各プレイヤーのデッキをシャッフル
2. 初期手札を4枚ドロー
3. 先攻プレイヤーをランダムに決定
4. ゲーム開始

---

### リソースシステム

#### マナ
マナはカードをプレイするために必要なリソースです。

**基本ルール**:
- ターン開始時に「最大回復マナ」分だけマナが回復
- 初期マナ: 1
- 最大マナ: 10
- ターンごとに最大回復マナが1増加（上限10）

**例**:
```
ターン1: マナ 1/1 → カード使用 → マナ 0/1
ターン2: マナ 2/2 → カード使用 → マナ 1/2
ターン3: マナ 3/3 → カード使用 → マナ 0/3
...
ターン10以降: マナ 10/10（最大）
```

#### HP
プレイヤーの体力を表します。

- 初期HP: 20
- 最大HP: 20（効果により増減可能）
- HPが0以下になると敗北

## カードシステム

### カードの種類

#### 1. ユニットカード（Unit）
フィールドに配置され、攻撃や防御を行います。

**パラメータ**:
- **コスト**: カードをプレイするために必要なマナ
- **攻撃力**: 攻撃時に与えるダメージ
- **守備力**: ユニットの耐久力
- **特性**: 特殊能力（Rush、Guardianなど）

**例**:
```
名前: ナイト
コスト: 3
攻撃力: 3
守備力: 3
効果: なし
```

#### 2. スペルカード（Spell）
即座に効果を発揮し、墓地に送られます。

**パラメータ**:
- **コスト**: カードをプレイするために必要なマナ
- **効果**: カードの効果（ダメージ、回復、ドローなど）
- **ターゲット**: 効果の対象（敵ユニット、味方、プレイヤーなど）

**例**:
```
名前: ファイアボール
コスト: 3
効果: 敵ユニットまたはプレイヤーに3ダメージを与える
```

#### 3. リーダーカード（Leader）
プレイヤーを代表する特別なカード（未実装）

---

### カードの特性（Trait）

#### Rush（突進）
召喚したターンに攻撃できます。

```
通常: ユニット召喚 → 召喚酔い → 次ターンから攻撃可能
Rush: ユニット召喚 → 即座に攻撃可能
```

**使用例**:
```
名前: Rush Knight
コスト: 3
攻撃力: 3
守備力: 2
特性: Rush
```

#### Guardian（守護）
相手は他のユニットを攻撃する前に、このユニットを攻撃しなければなりません。

```
相手の攻撃:
- Guardian持ちユニットが存在 → 強制的にGuardianを攻撃
- Guardian持ちユニットが不在 → 自由に攻撃対象を選択
```

**使用例**:
```
名前: Guardian
コスト: 4
攻撃力: 2
守備力: 5
特性: Guardian
```

#### Lifesteal（吸血）
与えたダメージ分、自分のHPを回復します。

```
攻撃力3のLifestealユニットが攻撃
→ 相手に3ダメージ
→ 自分が3回復
```

#### Quick（迅速）
即座に行動可能（召喚酔いなし、Rush相当）

## 戦闘システム

### 攻撃の基本ルール

#### 攻撃可能条件
1. 自分のターンである
2. メインフェーズである
3. ユニットが召喚酔い状態でない（Rushを除く）
4. ユニットがまだ攻撃していない

#### ターゲット選択

**通常の場合**:
- 相手プレイヤー
- 相手のユニット

**Guardian持ちユニットがいる場合**:
- 強制的にGuardian持ちユニットを攻撃
- すべてのGuardianが破壊されるまで他を攻撃不可

---

### ダメージ計算

#### ユニット vs ユニット
両方のユニットが相互にダメージを与えます。

```
攻撃側: 攻撃力3、守備力2
防御側: 攻撃力4、守備力3

結果:
- 攻撃側は3ダメージを与える → 防御側の守備力 3 - 3 = 0（破壊）
- 防御側は4ダメージを与える → 攻撃側の守備力 2 - 4 = -2（破壊）
- 両方とも破壊される
```

#### ユニット vs プレイヤー
ユニットの攻撃力分、プレイヤーのHPを減らします。

```
攻撃力5のユニットがプレイヤーを攻撃
→ プレイヤーのHP 20 - 5 = 15
```

---

### 破壊処理

#### ユニットの破壊
守備力が0以下になったユニットは破壊され、墓地に送られます。

**タイミング**:
1. ダメージ計算
2. 破壊判定
3. 破壊処理
4. 破壊時効果の発動（実装予定）

## 効果システム

### 効果の種類

#### 1. ダメージ（Damage）
対象にダメージを与えます。

**パラメータ**:
- `value`: ダメージ量
- `targetType`: ターゲットタイプ（敵ユニット、プレイヤーなど）

**例**:
```json
{
  "type": "DAMAGE",
  "value": 3,
  "targetType": "ENEMY_UNIT"
}
```

#### 2. 回復（Heal）
対象のHPを回復します。

**パラメータ**:
- `value`: 回復量
- `targetType`: ターゲットタイプ

**例**:
```json
{
  "type": "HEAL",
  "value": 5,
  "targetType": "SELF_PLAYER"
}
```

#### 3. ドロー（Draw）
カードを引きます。

**パラメータ**:
- `value`: ドロー枚数

**例**:
```json
{
  "type": "DRAW",
  "value": 2
}
```

#### 4. マナ操作（Mana）
マナを増減します。

**パラメータ**:
- `value`: 増減量
- `operator`: ADD（加算）、SET（設定）

**例**:
```json
{
  "type": "MANA",
  "value": 2,
  "operator": "ADD"
}
```

#### 5. ステータス変更（Modify）
ユニットの攻撃力や守備力を変更します。

**パラメータ**:
- `value`: 変更量
- `operator`: ADD（加算）、SET（設定）、MULTIPLY（乗算）
- `targetType`: 対象

**例**:
```json
{
  "type": "MODIFY_ATTACK",
  "value": 2,
  "operator": "ADD",
  "targetType": "ALLY_UNIT"
}
```

#### 6. 破壊（Destroy）
対象を破壊します。

**パラメータ**:
- `targetType`: 対象

**例**:
```json
{
  "type": "DESTROY",
  "targetType": "ENEMY_UNIT"
}
```

---

### 効果のタイミング

#### OnSummon（召喚時）
ユニットが召喚された時に発動します。

```go
card := entity.Card{
    Name: "Healing Knight",
    CardEffect: &entity.CardEffect{
        Definitions: []entity.EffectDefinition{
            {
                Type:    entity.EffectTypeHeal,
                Value:   3,
                Timing:  entity.EffectTimingOnSummon,
                TargetType: entity.TargetTypeSelfPlayer,
            },
        },
    },
}
```

#### OnDeath（死亡時）
ユニットが破壊された時に発動します（実装予定）。

#### OnTurnStart（ターン開始時）
自分のターン開始時に発動します（実装予定）。

#### OnTurnEnd（ターン終了時）
自分のターン終了時に発動します（実装予定）。

---

### ターゲットタイプ

| ターゲットタイプ | 説明 |
|----------------|------|
| `ENEMY_PLAYER` | 相手プレイヤー |
| `SELF_PLAYER` | 自分 |
| `ENEMY_UNIT` | 相手のユニット |
| `ALLY_UNIT` | 味方のユニット |
| `ALL_ENEMY_UNITS` | 相手のすべてのユニット |
| `ALL_ALLY_UNITS` | 味方のすべてのユニット |
| `ALL_UNITS` | すべてのユニット |
| `RANDOM_ENEMY_UNIT` | ランダムな相手ユニット |

## ターンフロー

### フェーズ

#### 1. ターン開始フェーズ（TurnStart）
```
- ターン番号インクリメント
- ターン開始時効果の発動（実装予定）
```

#### 2. リソース増加フェーズ（Resource）
```
- 最大回復マナを1増加（上限10）
- 現在マナを最大回復マナ分回復
```

#### 3. ドローフェーズ（Draw）
```
- デッキからカードを1枚ドロー
- デッキが空の場合は敗北
```

#### 4. メインフェーズ（Main）
```
プレイヤーは以下の行動を任意の順序で実行可能:
- カードのプレイ（ユニット召喚、スペル使用）
- ユニットでの攻撃
- ターン終了
```

#### 5. ターン終了フェーズ（TurnEnd）
```
- ターン終了時効果の発動（実装予定）
- 次のプレイヤーにターンを渡す
```

---

### ターンの流れの例

```
【プレイヤー1のターン1】
1. ターン開始（ターン番号: 1）
2. マナ回復: 0 → 1
3. ドロー: カードA
4. メインフェーズ:
   - コスト1のユニットを召喚
5. ターン終了

【プレイヤー2のターン1】
1. ターン開始（ターン番号: 1）
2. マナ回復: 0 → 1
3. ドロー: カードB
4. メインフェーズ:
   - コスト1のスペルを使用
5. ターン終了

【プレイヤー1のターン2】
1. ターン開始（ターン番号: 2）
2. マナ回復: 0 → 2
3. ドロー: カードC
4. メインフェーズ:
   - 前ターンに召喚したユニットで攻撃
   - コスト2のユニットを召喚
5. ターン終了
```

## 勝利条件

### 通常勝利
相手プレイヤーのHPを0にする。

```
プレイヤーA HP: 5
プレイヤーB HP: 0
→ プレイヤーAの勝利
```

### デッキアウト勝利
相手のデッキが尽き、ドローできなくなったときに勝利。

```
プレイヤーAのターン開始
→ ドローフェーズ
→ デッキが空
→ プレイヤーBの勝利
```

## カードの設計原則

### コストカーブ
デッキは様々なコストのカードで構成されるべきです。

**理想的な配分**:
```
コスト1: 4-6枚
コスト2: 5-7枚
コスト3: 5-7枚
コスト4: 3-5枚
コスト5+: 3-5枚
```

### バランス調整の指針

#### ユニットの基本値
```
攻撃力 + 守備力 ≈ コスト × 2

例:
コスト3 → 攻撃3 + 守備3 = 6
コスト4 → 攻撃4 + 守備4 = 8
```

#### 特性の価値
```
Rush: +0.5コスト相当
Guardian: +0.5-1コスト相当
Lifesteal: +1コスト相当
```

## まとめ

このゲームは、シンプルなルールでありながら戦略的な深さを持つカードゲームです。リソース管理、ターゲット選択、カードの使用タイミングなど、様々な要素を考慮してプレイする必要があります。

クリーンアーキテクチャを採用しているため、新しいカードや効果の追加が容易で、将来的な拡張性も高くなっています。
